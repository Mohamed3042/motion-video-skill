**Shortlist of design resources worth using when an agent (Codex, Claude Code, GPT) builds UI: give the agent rules and real references instead of letting it guess.**
#resource #design #ui

## Use first
1. **designmd.ai**: design systems written as Markdown an agent reads before building. Matches the user's workflow of handing GPT/Codex a written design "recipe" (the sheep app redesign prompt) and addresses "GPT sucks at web design".
2. **21st.dev**: component marketplace that plugs into agents via MCP, so the agent pulls finished components instead of hand-writing them.
3. **component.gallery**: how many real design systems solve the same element (tables, tabs, settings pages). Use when a screen feels off, e.g. a crowded MK Voice Live panel.

## Use when the project needs it
- Landing or marketing pages (MK Suite and similar): **motion-primitives.com**, **magicui.design**, plus **ui.shadcn.com** / **shadcnblocks.com** if the stack is shadcn.
- Motion and film work: **animejs.com**, **threejs.org**; **thebookofshaders.com** to learn shaders.
- Mobile patterns: **mobbin.com**.

## Inspiration only (browse, nothing to install)
godly.website, awwwards.com, minimal.gallery, land-book.com, landing.love, styles.refero.design, supahero.io, pricingpages.design, navbar.gallery, footer.design, cta.gallery.

## Skip
- **scrolltide.co**: paid prompt pack. The source post pushes it as "if you only open one link, make it this one", which reads as promotion. Bought prompts are not needed.
