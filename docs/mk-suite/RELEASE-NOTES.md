# MK Suite — See what you can do

A rebuilt 90-second, 1080p60 film showing 23 software workflows. Each scene now demonstrates an input, a user action and a visible result: audio conversion previews, music editing, camera alignment, design proofs, source-backed research, quotation export, reviewed operations and more. Each product keeps its own colour, composition and motion treatment.

The closing offer remains **One suite. One monthly subscription.** No subscription price is shown.

## Included

- `mk-suite-workflows.mp4`: full-quality H.264/AAC master.
- `MK-Suite-Workflows-Share.mp4`: smaller 1080p60 sharing copy.
- `MK-Suite-Workflows-Source.zip`: complete editable V1 and V2 visual/audio code, dependency lockfile, briefs, build tools and AI editing guide.
- The repository also includes the chaptered player, subtitle files, preview images and validation report. Clone it and open `outputs/mk-suite-workflows/index.html` to review or loop each product.

## Continue editing with another AI

Read [docs/mk-suite/EDITING.md](https://github.com/Mohamed3042/motion-video-skill/blob/main/docs/mk-suite/EDITING.md). Run `npm run setup`, `npm run check` and `npm run dev`. The master contains exactly 5,400 video frames. Full decode, audio measurements, onset timing and sampled visual reviews are recorded in [the production report](https://github.com/Mohamed3042/motion-video-skill/blob/main/docs/mk-suite/PRODUCTION.md). The mix has not been listened to.

These are illustrated product workflows with demo data, rather than live application recordings. Product availability varies; the subscription is a concept and free cores remain free.
